# Registro da montagem física

[English (default)](../../../examples/physical-build-record.md) | [Português (Brasil)](physical-build-record.md) | [Índice](../README.md)

Copie este modelo para armazenamento privado por rack/local. Campos vazios permanecem desconhecidos até medição.

| Campo | Medição / evidência |
|---|---|
| Modelo do rack ou revisão do desenho de engenharia | |
| U útil, largura, profundidade e espaço para manutenção | |
| Capacidade de carga de estrutura, trilhos, prateleiras e piso | |
| Inspeção de ancoragem e terra de proteção | |
| Capacidade de circuito/PDU/UPS e data da inspeção | |
| Chassis, posição U, massa e modelo do trilho | |
| GPU SKU, formato, fixação e peça do cabo de alimentação | |
| Temperatura de entrada/saída, repouso/carga e duração | |
| Potência em W e VA no repouso/carga/boot | |
| Ventiladores, dutos e resposta à falha de ventilação | |
| Desligamento por UPS e resultado da recuperação | |
| Mapa switch/porta/cabo/zona | |
| Fotos/desenhos com identificadores privados removidos | |
| Mudanças desde a execução anterior e reversão | |

Nunca publique senhas BMC, chaves Wi-Fi, credenciais WAN, seriais ou endpoints privados em fotos. Use o [módulo físico](../modules/01-roots-physical.md) como roteiro.
